# 06-recaps

Prompts et modèles pour les recaps, le livret CESI et la charte. Les DONNÉES sont dans `06-logs/`, ignoré par Git.

- `newlog` : crée le log du jour à partir du modèle
- `sanitize.prompt.md` : retirer tout ce qui est identifiant avant qu'un texte sorte du poste
- `weekly-recap.prompt.md` : recap hebdomadaire court pour le tuteur
- `competence-coverage.prompt.md` : où j'en suis sur les 12 compétences
- `livret-draft.prompt.md` : brouillons des textes du livret (jamais les notes)
- `charte-chantier.prompt.md` : construire la charte du chantier d'application
- `monthly-rollup.prompt.md` : bilan mensuel ou semestriel
- `weekly-routine.md` : quoi faire, quand, et où vit chaque fichier
