# 01-understand-codebase

Ordre conseillé sur un dépôt inconnu :
1. `core/map-the-repo.prompt.md` : la structure et les technologies
2. `core/run-locally.prompt.md` : le lancer en local
3. `core/read-the-history.prompt.md` : ce qui a été fait, quand, pourquoi
4. `core/architecture-summary.prompt.md` : composants, flux, décisions
5. `core/big-picture.prompt.md` : à quoi ça sert, pour qui, où ça s'insère, et les questions à poser
6. Entretiens courts avec les humains, guidés par `big-picture-questions.md`
7. `core/who-owns-what.prompt.md` : à qui poser quelles questions
8. `core/tech-debt-and-risks.prompt.md` : où être prudent
9. Compléter `codebase-map-template.md`, puis la montrer au référent technique

Modules selon le type de mission : `module-rag-ai.md`, `module-cloud.md`, `module-unknown-stack.md`.
Tout ce qui sort des prompts est à vérifier dans le code, et le pourquoi métier se confirme auprès des personnes.
