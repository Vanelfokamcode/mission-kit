1. `core/map-the-repo.prompt.md` : la structure et les technologies
2. `core/run-locally.prompt.md` : le lancer en local
3. `core/read-the-history.prompt.md` : ce qui a été fait, quand, pourquoi
4. `core/architecture-summary.prompt.md` : composants, flux, décisions
5. `core/who-owns-what.prompt.md` : à qui poser quelles questions
6. `core/tech-debt-and-risks.prompt.md` : où être prudent
7. Compléter `codebase-map-template.md`, puis la montrer au référent technique

Modules selon le type de mission : `module-rag-ai.md`, `module-cloud.md`, `module-unknown-stack.md`.
Tout ce qui sort des prompts est à vérifier dans le code avant d'être répété.
