# Schéma d'architecture

Réponds en français. À partir de ce que je te donne (description, README, code d'infrastructure) : [COLLER].

## Ce que tu produis
1. Un schéma Mermaid dans un bloc de code de type `mermaid` (GitHub l'affiche dans les fichiers Markdown) :
   composants, flux (sens des flèches), frontières (réseaux, comptes, environnements). 15 éléments maximum :
   si c'est plus gros, découpe en plusieurs schémas.
2. Une légende : un mot par type d'élément.
3. Les éléments déduits ou incertains, marqués dans le schéma (pointillés) et listés.
4. Une version simplifiée pour un public non technique, en 5 éléments maximum.
5. Les questions à poser pour compléter ou corriger.

## Règles
- Ne dessine que ce qui est vu ou clairement déduit : [vu], [déduit], [inconnu].
- Pas de nom interne identifiant si le schéma peut sortir de l'équipe : des noms génériques.
- Un schéma sans légende ni date n'aide personne : ajoute la date et la version lue.
