# 00-start-here

À lire et à utiliser avant et pendant les premiers jours d'une mission.

1. `day1-playbook.md` : la page de lancement, à suivre dans l'ordre le jour 1
2. `confidentiality-checklist.md` : à parcourir avant toute chose, et à compléter avec les vraies règles
3. `day1-questions.md` : les questions à poser, à cocher au fil des réponses
4. `first-3-hours.md` : la méthode pour comprendre une pile inconnue sans rien casser

Les réponses obtenues vont dans le log du jour 1 (voir `02-daily/`).
