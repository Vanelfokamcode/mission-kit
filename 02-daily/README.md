# 02-daily

Ordre d'utilisation :
1. Matin : `start-of-day.prompt.md` (contexte, objectifs, questions pour le stand-up)
2. Après le stand-up : `plan-my-day.prompt.md` (todo -> planning 9h-17h)
3. Soir : `end-of-day.prompt.md` (log complet + version assainie, avec codes de compétences)

Références : `competences.md` (12 compétences du livret) et `daily-log-template.md` (format du log).
Le log complet reste sur le poste de travail. Seule la version assainie peut en sortir,
après vérification de ce qu'Accenture autorise.
